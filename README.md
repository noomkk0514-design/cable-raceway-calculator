# Cable & Raceway Calculator

แอปคำนวณสำหรับงานออกแบบระบบไฟฟ้า (PWA) ติดตั้งลงมือถือ/คอมพิวเตอร์ได้ และใช้งานออฟไลน์ได้หลังเปิดครั้งแรก

- **ออกแบบวงจร** — เลือกเบรกเกอร์ ขนาดสายเฟส/นิวทรัล สายดิน แรงดันตก และขนาดท่อจากโหลด
- **แรงดันตก** — ΔV, % และความยาวสูงสุดที่ยอมให้
- **ท่อร้อยสาย** — EMT / IMC / RSC ตามเกณฑ์ 53 / 31 / 40 %
- **รางเดินสาย / รางเคเบิล** — Wireway 20 %, Cable tray ตามพื้นที่และวางชั้นเดียว
- **ตารางอ้างอิง** — พิกัดกระแสตามวิธีติดตั้ง สายดิน ขนาดท่อ

> ค่าในตารางเป็นค่าอ้างอิงเพื่อการออกแบบเบื้องต้น ต้องตรวจสอบกับมาตรฐาน วสท. ฉบับที่ใช้บังคับและข้อมูลผู้ผลิตก่อนใช้งานจริง

## โครงสร้าง
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวแอป |
| `manifest.webmanifest` | ชื่อแอป ไอคอน สี ทางลัด |
| `sw.js` | Service worker สำหรับใช้งานออฟไลน์ |
| `icons/` | ไอคอนแอป |
| `dev/` | ไฟล์ต้นฉบับและสคริปต์สร้าง `index.html` / ไอคอน (ไม่จำเป็นต่อการใช้งาน) |

## เปิดใช้ GitHub Pages
Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
รอ 1–2 นาที แอปจะอยู่ที่ `https://<username>.github.io/<ชื่อ repo>/`

## ติดตั้งแอป
- **Android / Chrome / Edge:** กดปุ่ม "ติดตั้งแอป" มุมขวาบน
- **iPhone / iPad (Safari):** ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม

## อัปเดตเวอร์ชัน
1. แก้ `dev/cable-raceway-calculator.html`
2. สร้าง `index.html` ใหม่: `python dev/tools/build_pwa.py dev/cable-raceway-calculator.html index.html`
3. เปลี่ยน `VERSION` ใน `sw.js` (เช่น `crc-v1` → `crc-v2`)
4. อัปโหลดไฟล์ที่เปลี่ยนขึ้น GitHub — ผู้ใช้จะเห็นแถบ "มีเวอร์ชันใหม่ · อัปเดต"
